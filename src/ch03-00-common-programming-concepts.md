# Conceitos Comuns de Programação {#common-programming-concepts}

Este capítulo aborda conceitos que aparecem em quase todas as linguagens de
programação e como eles funcionam em Rust. Muitas linguagens de programação têm
muito em comum em seu núcleo. Nenhum dos conceitos apresentados neste capítulo
é exclusivo do Rust, mas vamos discuti-los no contexto do Rust e explicar as
convenções para usá-los.

Especificamente, você vai aprender sobre variáveis, tipos básicos, funções,
comentários e controle de fluxo. Essas bases estarão em todo programa Rust, e
aprendê-las cedo vai dar a você um núcleo sólido para começar.

> #### Palavras-chave
>
> A linguagem Rust tem um conjunto de _palavras-chave_ reservadas para uso
> exclusivo da linguagem, assim como em outras linguagens. Tenha em mente que
> você não pode usar essas palavras como nomes de variáveis ou funções. A
> maioria das palavras-chave tem significados especiais, e você as usará para
> realizar diversas tarefas nos seus programas Rust; algumas não têm nenhuma
> funcionalidade atual associada, mas foram reservadas para funcionalidades que
> podem ser adicionadas ao Rust no futuro. Você pode encontrar a lista de
> palavras-chave no [Apêndice A][appendix_a]<!-- ignore -->.
