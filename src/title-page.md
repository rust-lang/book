# A Linguagem de Programação Rust {#the-rust-programming-language}

_por Steve Klabnik, Carol Nichols e Chris Krycho, com contribuições da
Comunidade Rust_

Este texto assume que você está usando o Rust 1.99.1 (lançado em 2026-10-15)
ou uma versão posterior, com `edition = "2024"` no arquivo *Cargo.toml* de
todos os projetos, para configurá-los com as construções idiomáticas da edição 2024 do Rust.
Veja a [seção “Instalação” do Capítulo 1][install]<!-- ignore --> para
instruções sobre como instalar ou atualizar o Rust, e veja o [Apêndice
E][appendix-e]<!-- ignore --> para informações sobre as edições.

O formato HTML está disponível online em
[https://doc.rust-lang.org/stable/book/](https://doc.rust-lang.org/stable/book/)
e offline nas instalações do Rust feitas com o `rustup`; execute `rustup doc
--book` para abri-lo.

Há também várias [traduções][translations] feitas pela comunidade.

Este texto está disponível em [formato impresso e e-book pela No Starch
Press][nsprust].
