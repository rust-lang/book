# Prefácio {#foreword}

A linguagem de programação Rust percorreu um longo caminho em poucos anos, desde
sua criação e incubação por uma pequena comunidade inicial de entusiastas, até
se tornar uma das linguagens de programação mais queridas e procuradas do
mundo. Olhando para trás, era inevitável que o poder e a promessa do Rust
chamassem a atenção e ganhassem espaço na programação de sistemas. O que não
era inevitável foi o crescimento global de interesse e de inovação que se
espalhou pelas comunidades de código aberto e impulsionou uma adoção em larga
escala em diversos setores.

Neste momento, é fácil apontar as ótimas funcionalidades que o Rust oferece para
explicar essa explosão de interesse e de adoção. Quem não quer segurança de
memória, *e* desempenho rápido, *e* um compilador amigável, *e* ótimas
ferramentas, entre tantas outras funcionalidades maravilhosas? A linguagem Rust
que você vê hoje combina anos de pesquisa em programação de sistemas com a
sabedoria prática de uma comunidade vibrante e apaixonada. Essa linguagem foi
projetada com propósito e feita com cuidado, oferecendo aos desenvolvedores uma
ferramenta que facilita escrever código seguro, rápido e confiável.

Mas o que torna o Rust verdadeiramente especial são as suas raízes em dar poder
a você, o usuário, para alcançar seus objetivos. Esta é uma linguagem que quer
que você tenha sucesso, e o princípio de empoderamento atravessa o núcleo da
comunidade que constrói, mantém e defende essa linguagem. Desde a edição
anterior deste texto definitivo, o Rust evoluiu ainda mais para se tornar uma
linguagem verdadeiramente global e confiável. O Projeto Rust agora é
sustentado de forma robusta pela Rust Foundation, que também investe em
iniciativas-chave para garantir que o Rust seja seguro, estável e sustentável.

Esta edição de *The Rust Programming Language* é uma atualização completa, que
reflete a evolução da linguagem ao longo dos anos e traz informações novas e
valiosas. Mas não é apenas um guia de sintaxe e de bibliotecas: é um convite
para fazer parte de uma comunidade que valoriza qualidade, desempenho e um
design cuidadoso. Seja você um desenvolvedor experiente que quer explorar o Rust
pela primeira vez, seja um Rustacean experiente que quer aprimorar suas
habilidades, esta edição tem algo para todo mundo.

A jornada do Rust tem sido de colaboração, aprendizado e iteração. O
crescimento da linguagem e do seu ecossistema é um reflexo direto da comunidade
vibrante e diversa por trás dela. As contribuições de milhares de
desenvolvedores, de projetistas da linguagem a colaboradores eventuais, são o
que tornam o Rust uma ferramenta tão única e poderosa. Ao pegar este livro,
você não está apenas aprendendo uma nova linguagem de programação: está se
juntando a um movimento para tornar o software melhor, mais seguro e mais
agradável de trabalhar.

Bem-vindo à comunidade Rust!

- Bec Rumbul, Diretora Executiva da Rust Foundation
